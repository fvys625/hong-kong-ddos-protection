## GoMami 的 600Gbps 防御是自带的吗？不是

所有实例默认只有 **best-effort 基础清洗**：免费、自动检测异常流量、不需要配置。官方文档的表述是基础清洗为 best-effort，防护能力随攻击规模与网络状况变化，不承诺固定防护阈值；600 Gbps 专业清洗属于**付费附加服务**，文档只写“联系销售或访问网站了解详情”，没有公开标价。

还有一条比防御容量更值得注意的条款：

> 当实例遭遇大规模 DDoS 攻击、影响到同一网段其他客户的正常使用时，系统会对该 IP 执行黑洞（null route）：持续 30–60 分钟，自动解除，**无法人工干预**。黑洞期间进出流量全部丢弃，服务不可用。

这条规则直接决定适用边界。如果你的业务是游戏服、金融类应用，或者任何“被打十分钟就等于损失订单”的场景，只买基础防护的套餐并不合适——攻击大到影响邻居时，你会被迫下线半小时以上，而且没人能提前解封。真要稳定扛攻击，得走 600Gbps 付费清洗那条路，报价需要单独联系销售确认。

防护覆盖的攻击类型列得比较清楚：L3/L4 层包括 UDP Flood、SYN Flood、ACK Flood、ICMP Flood、DNS 放大、NTP 放大；L7 层包括 HTTP Flood、CC、Slowloris。文档还给了 iptables 示例，建议自己限制 SYN 速率、丢弃无效包、限制 ICMP 速率——这等于承认基础防护之外的自保动作仍然必要。

## 三网直连走的是哪几条线，香港凭什么最贵

官方给的说法是 Triple-Network Direct：电信 CN2、联通 AS9929、移动 CMI 直连，按来源 IP 智能选回程，多上游冗余自动切换。延迟口径分节点写得很清楚：香港 < 30ms、日本 < 50ms、新加坡 < 70ms，整体对大陆 RTT < 50ms。

第三方测评补充了更细的信息：香港机房位于 Equinix HK2，回程三网分别走 CN2 GIA（AS4809）、9929（AS9929/AS10099）、CMIN2（AS58807）。这部分官网页面没有确认，当参考看。

对实际使用的影响是这样的：移动用户晚高峰最容易出问题，CMI/CMIN2 直连的意义就在这里；联通走 9929 而不是绕道国际出口，电信走 CN2 而不是普通 163 骨干。GoMami 香港节点把这三条线都做了，并按来源 IP 自动选回程——这是它敢按 $49 起卖的底气所在。只走其中一条线的产品，在另外两家运营商用户那里的表现会打折。

## 从下单到拿到 IP：两个容易踩的坑

流程本身不复杂：登录后左侧选节点（Hong Kong / Japan / Singapore），再选产品线（HKG Turin / HKG Pulse / HKG Forge），挑套餐，付款，系统自动部署，通常几分钟内完成，IP 和登录凭证发到邮箱。之后换 IP、买流量包、实例转移都能在面板自助操作，还提供 RESTful API 做程序化管理。

第一个坑是**首页价格和 store 页价格不是一套**。官网首页展示的套餐面板与 store 页价格不一致，疑为旧版或未按系列区分，下单只认 store 页和结账页显示的数字。

第二个坑是**优惠码一单只能用一张**。同一订单填两个码不会叠加，系统通常只认折扣力度最大的那张。填完记得看订单摘要里有没有 Recurring 字样，确认 8 折是循环的而不是只首期。

## 常见问题

**香港高防云服务器需要备案吗？**

**600Gbps 防御是所有套餐都带吗？**
不带。所有实例默认只有免费的 best-effort 基础清洗，不承诺固定防护阈值；600Gbps 专业清洗是付费附加服务，价格需要联系销售确认。

**被打了会怎么样？**
基础清洗会自动检测并清洗异常流量，正常流量不受影响。如果攻击规模大到影响同网段其他客户，你的 IP 会被黑洞 30–60 分钟，自动解除，无法人工提前解封。

**流量用完了怎么办？**
可以自助购买流量包（100GB $6 起），不必升级套餐。Forge 独服则是按 $0.06/GB 计费，不限速。

**能用 Windows 吗？**
Pulse 的 Pro／Ultra 和 Turin 的 Pro／Ultra 标注 Windows-ready，入门款没有标。

**香港、日本、新加坡怎么选？**
看用户在哪。大陆用户为主选香港（< 30ms）；预算有限、对延迟没那么苛刻，日本和新加坡同配置起步便宜 $10 左右；面向东南亚业务选新加坡。
